# Houston Headstones Website

Professional static website for **Houston Headstones by Bedrock Boulders** — focused exclusively on custom polished granite headstones and memorials.

## Deploy to GitHub Pages (Free)

1. Create a new GitHub repository (e.g. `houston-headstones` or use your username for `username.github.io`).
2. Upload all files and folders in this directory to the repository root (or a `/docs` folder if preferred).
3. In repository **Settings → Pages**:
   - Source: Deploy from a branch
   - Branch: `main` (or `master`), folder `/ (root)`
4. Save. Your site will be live at `https://yourusername.github.io/repo-name/` within a few minutes.
5. (Optional) Point your custom domain `houstonheadstones.com` to GitHub Pages in the same Settings → Pages section and update DNS with your registrar.

## Form Handling

The contact form uses Formspree.  
Replace the form endpoint in `contact.html` with your Formspree form ID if needed (sign up at formspree.io).  

Alternatively, change the form `action` to a `mailto:` link or use Netlify Forms if you later move hosting.
