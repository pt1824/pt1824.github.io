# Law Office of Keval Patel – New Website

Professional, modern, SEO-optimized static website for the Law Office of Keval Patel, civil attorney in Sugar Land, Texas.

## Features

- Clean, responsive design (mobile-first)
- Semantic HTML5 + Schema.org markup (Attorney / LocalBusiness)
- Unique title tags, meta descriptions, and Open Graph tags on every page
- Canonical URLs and sitemap.xml / robots.txt
- Accessible navigation and form labels
- Fast-loading (minimal JS, optimized CSS)
- Practice area pages optimized for local search keywords
- Contact form (client-side demo – connect to Formspree, Netlify Forms, or backend in production)
- Professional navy & gold color scheme suitable for a law firm

## Pages

- `index.html` – Home

## Deployment

This is a pure static site. You can host it on:

- Netlify / Vercel / Cloudflare Pages (drag-and-drop or Git)
- Traditional web hosting (upload via FTP)
- GitHub Pages

Replace the placeholder Google Map section on the contact page with an actual embed from Google Maps.

Connect the contact form to a real backend or form service before going live.

Update the domain references in canonical tags, schema, and sitemap if the final domain differs.
